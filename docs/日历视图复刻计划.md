# 日历视图复刻计划（滴答清单基线）

> 依据：2026-10-28 用户提供的 30 张滴答清单日历截图（窗口 1080×608，含日/周/月/年/日程/多日/多周、快速添加、详情浮层、显示设置、安排任务）。本文件只描述**分批边界与验收口径**，每个批次完成后在 `docs/Phase2-前端改造.md` 追加 P2-CAL 记录，并在 `docs/前端手工检查清单.md` 追加浏览器验收小节。

## 1. 目标与约束

1. 以截图为唯一视觉与交互基线，重做任务日历页（`/tasks/calendar`），保留既有后端契约与离线同步模型。
2. 页面必须整块占满可用视口（复用 `.workspace-topbar.task-domain-topbar` 的全幅规则），页面内部自滚动，不出现页面级滚动条。
3. 侧栏在窄宽度下自动收起，可用工具栏按钮手动切换；手动选择在本次会话内优先于自动收起。
4. 数据来源分层：任务/清单/标签/习惯/倒数日优先读本地 store（字段完整、支持离线），节假日与农历读 `/api/v1/tasks/calendar` 聚合接口，专注记录读 `/focus/sessions?from&to`。
5. 未实现的入口不渲染，不用占位按钮。

## 2. 能力盘点（对照截图）

| 截图要求 | 现有契约 | 结论 |
|---|---|---|
| 任务块、跨天任务、全天任务 | `startAt/dueAt/allDay/durationMinutes` | 可直接支持 |
| 重复任务图标 | `rrule`、`seriesId` | 可支持 |
| 检查项 `+N` | `checklist` | 可支持 |
| 习惯行与打卡态 | `habit` + `habit-checkin`（`CUSTOM` 外每日排期） | 可支持，前端复算排期 |
| 倒数纪念日 | `countdown`（`repeatYearly`） | 可支持 |
| 专注记录（番茄块） | `GET /focus/sessions?from&to` | 可支持 |
| 节假日/农历 | 聚合接口 `layers=holiday&lunar=1` | 可支持 |
| 订阅日历日程（第三方 ICS 导入） | **无**（仅有 ICS 导出 feed） | **不做**（2026-10-28 用户确认取消） |
| 工时/流水叠加 | 聚合接口 `layers=worktime,ledger` | 仅系统级日历 `/calendar` 显示，任务日历不显示（B2 已实现） |

## 3. 分批计划

### B1 骨架、侧栏、工具栏、月视图 ✅ 2026-10-28

- 纯函数层：`calendarRange.js`（视图枚举、范围解析、ISO 周序号、年视图月网格、标题、锚点位移）、`calendarEvents.js`（任务/习惯/倒数日/专注 → 按天分桶）、`calendarColors.js`（按清单/标签/优先级取色、习惯与倒数日取色）。
- 三栏骨架：侧栏（迷你月历 + 范围选择）、主区（工具栏 + 视图容器）、第三栏预留。
- 工具栏：侧栏开关、标题、新增、视图菜单（日/周/月/年/日程 + 多日 1–14、多周 2–6 步进）、上一段/今天/下一段、更多菜单。
- 侧栏：迷你月历（月份标题、前后翻月、点击定位今天/选中日、农历副标）、所有/清单/标签/过滤器四组范围选择（标题框全选联动、过滤器单选互斥）。
- 月视图：周序号 + 7 列 × 4–6 行，日号/农历/今天标记，事件条（颜色点 + 标题 + 时间 + 完成态），溢出 `+N` 按格高动态计算。
- 显示设置（任务页签）：按清单/标签/优先级着色，即时生效并持久化。
- 响应式：窄于 1180px 自动收起侧栏。

### B2 月/多周交互补齐 ✅ 2026-10-28

跨天事件泳道（按周压条、重叠分配泳道、跨周裁切）、点击日期浮层（当日事件列表 + 快速添加）、月/多周左右滑动翻页、多周逐行吸附（`scroll-snap`）、`+N` 溢出按泳道占位重算。

同批按用户决策调整：**任务日历（`/tasks/calendar`）不显示工时与流水；工时与流水叠加改由系统级日历（`/calendar`）承担**（图层参数 `worktime,ledger,holiday`），并**彻底移除订阅日历需求**。

### B3 单日/多日时间轴 ✅ 2026-10-28

全天区（可折叠、下拉拖拽调高）、0–24 时间轴（默认收起 00:00–07:00 与 23:00–24:00，上下沿可拖拽调整并持久化）、时间块（重叠自动分列、短块横排、左侧色条；整日对齐的跨天任务提升到全天区，不再占用时间轴）、专注块、当前时间线、跨天有刻事件的裁切与虚线「续」标记、点击空白时段按 15 分钟吸附直接新建带时间的任务。

### B4 快速添加四种入口 ✅ 2026-10-28

- 全天区点击空白：以该日期新建全天任务（不占用时间轴）。
- 时间轴拖出区间：按下空白时段竖向拖动，实时显示虚线选区与「13:45 – 15:45 · 2 小时」，松手后弹出卡片并新建对应时长的有刻任务。
- 月格拖选多天：在月/多周视图按住日期横向拖动，跨格高亮并新建跨天任务（起止按本地零点对齐，末日含当天）。
- 时间块拖动：按住块体上下拖动改时间（保持时长），按上下边把手拖拽改起止；两者都按 15 分钟吸附并写回服务端。

### B5 对象详情浮层 ✅ 2026-10-28

点击日历上的任务条 / 时间块 / 习惯 / 倒数日 / 专注记录，在指针旁弹出原位卡片，不离开日历上下文：

- 任务：完成/恢复、优先级四档、移动清单、到期时间与清单信息、未完成检查项数量、专注（25 分钟）、打开详情、删除。
- 习惯：当天打卡状态、我做到了 / 撤销、连续天数提示、进入习惯页。
- 倒数日：重复规则与目标日期、进入倒数日页。
- 专注记录：起止时间与完成状态、进入专注页。

### B6 周视图 ✅ 2026-10-28

7 列共享时间轴与全天区；列头日期 + 星期 + 农历，今天实心圆与整列淡底；左侧时间轴沟槽显示周序号（竖排「44周」）；多列视图按 88px 列宽下限横向滚动（滚动留在日历内部，不产生页面级溢出）；跨天任务在全天区以连续横条跨列显示，有刻的跨夜任务按天裁切并标虚线与「接前一天/延续到次日」。

### B7 年视图 ✅ 2026-10-28

12 个月网格，每月带 ISO 周序号列；有事件的日期高亮并带圆点，今天实心圆；点击日期弹出当日事件浮层（含「打开日视图」直接跳转），点击月份标题进入该月；今天在相邻月的补位格里也会高亮（与月视图补位一致）。

### B8 日程视图 ✅ 2026-10-28

按天分组的时间线，日期头吸顶（当天日程滑过后随分组一起离开）；进入视图或点「今天」时自动把今天滚到顶部；无安排的日期不占位；行内左侧为时间（全天/09:00），右侧为未完成检查项数；点击行打开事件卡片。

### B9 显示设置完整 ✅ 2026-10-28

任务 / 习惯 / 倒数纪念日三个页签（系统日历另有「叠加层」页签）；任务按清单/标签/优先级、习惯按主题色/固定色/习惯色、纪念日按固定色/纪念日色；点颜色块弹出色板（推荐 / 马卡龙 / 莫兰迪 / 洛可可 / 经典 / 孟菲斯 + 自定义 HEX），选中即时写回清单、习惯或纪念日。

### B10 安排任务第三栏 ✅ 2026-10-28

更多菜单 →「安排任务」在日历右侧展开第三栏：

- 分组：按清单 / 按标签 / 按优先级，组内按优先级与排序值排列，组标题带颜色点与计数。
- 筛选：无日期（默认开）与已过期两个可独立开关的桶，两者都关时展示全部待安排任务。
- 选项：隐藏笔记、隐藏任务层级（隐藏子任务缩进，只留顶层任务）。
- 排期：任务行可拖到月格（排成当天全天任务）或时间轴（排成 30 分钟有刻任务），也可以直接点行排到当前选中日期；成功后提示「已安排到 X月X日」。
- 面板开关与分组/筛选偏好按账号持久化；窄屏下面板改为覆盖式抽屉。

### B11 收尾 ✅ 2026-10-28

更多菜单的打印拆成「缩略打印」（只保留色条与日期格，隐藏标题/时间）与「打印详细」（完整信息）；系统日历的显示设置新增「叠加层」页签，可独立开关工时、流水、节假日与调休、习惯完成情况，关闭后该层不再请求与绘制。

订阅日历（外部 ICS 导入）已按用户决策取消，不再排期。
