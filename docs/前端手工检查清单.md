# 前端手工检查清单

> 建立日期：2026-09-28
> 维护方式：每个增量结束时更新。自动化 Agent 不执行浏览器操作、截图或视觉验收；以下项目由用户在空闲时手工检查。Node 测试、类型检查、OpenAPI 检查和生产构建仍由自动化流程执行。

## 使用说明

1. 先确认本地后端健康、前端开发服务可访问，并记录本次检查对应的 Git 提交。
2. 按增量章节逐项操作；通过后将 `[ ]` 改为 `[x]`，发现问题时在该项下记录现象、浏览器、视口、主题和复现步骤。
3. 桌面建议至少检查 Chromium 或 Safari/WebKit；移动端建议检查 375px 宽度或真实手机。
4. 涉及写入的流程应使用测试数据，并确认传统页面、本地投影和刷新恢复结果一致。
5. 构建通过不等于页面验收通过；未由用户勾选的项目保持“待手工检查”。
