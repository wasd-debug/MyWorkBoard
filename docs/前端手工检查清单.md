# 前端手工检查清单（按页面顺序）

> 最近整理：2026-10-12。正文按实际页面和导航入口排列，同一页面跨增量的检查项集中在一起。增量、提交与自动门禁只保留在文末验证记录中。

## 使用方式与结果口径

- 本仓库默认不使用浏览器自动化、截图或交互式浏览器验证；只有用户对具体任务明确授权时才能执行。`[x]` 表示该条描述的范围已实际检查通过，`[ ]` 表示未覆盖、未完整覆盖或检查失败。
- 准备至少两个普通测试账号、含一二级分类和多笔流水的账本、不同状态/日期/优先级的任务，以及工时、习惯、专注和倒数日数据。
- 页面检查至少覆盖桌面 ≥1280px、平板 768-1024px、手机 320/375px、亮色和暗色主题；核心流程补充键盘操作、空状态、加载态、失败态和长文本。
- 涉及离线能力时先在线加载数据，再断网操作、刷新、恢复网络并核对同步；涉及权限时切换两个账号，检查本地投影、服务端数据和错误信息均不串用。
- 失败时记录页面、浏览器、视口、主题、账号/数据状态、复现步骤和截图位置；不得暴露 PAT、API Key、OAuth 凭据或 ICS 完整 token。
- 自动测试、类型检查、OpenAPI 一致性和生产构建通过，不等于视觉、真实浏览器、真机或外部客户端验收通过。

本轮自动门禁环境：本地 Docker 前端 `http://localhost/`；未执行浏览器自动化、截图或 DOM 检查。需要视觉、响应式、键盘焦点和真实写入验收时，使用独立 QA 账号按本清单手工记录。
