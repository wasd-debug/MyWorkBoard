# AI 工作台静态草稿

## 目的

本草稿用于确认前端信息架构和视觉方向，不接入现有 Vue 路由、Pinia 状态、OpenAPI 客户端或后端 API。它不改变 Phase 0/1 已完成的账本与工时功能，也不表示 Phase 2 任务域或 Phase 3 RAG/Agent 已经实施。

## 入口与预览方式

- 草稿文件：`frontend/drafts/ai-workspace.html`
- 使用浏览器直接打开该文件，或在 `frontend/` 目录执行 `npx vite --host 127.0.0.1` 后访问 `/drafts/ai-workspace.html`。

## 设计决策

1. 首页改为 AI 对话入口，支持四类快捷意图：记账、整理知识、补录工时、安排任务。
2. 账本与工时作为当前已实现的独立应用空间；知识库、任务保留为未来 AI 工作台入口，并明确展示“即将开放”，不虚构现有业务数据。
3. 色彩遵循设计参考：账本为淡黄、知识库为青绿、工时为粉色、任务为杏色；深色用于主操作和选中状态。
4. 配色切换不放入主导航；桌面端收纳在顶部“配色”菜单，手机端收纳在“更多”，设置页也提供同一组色板，避免小屏顶部拥挤。
5. 页面、对话框、领域卡片和工时柱状图具有轻量入场动效；系统开启“减少动态效果”时自动停用。
6. AI 对话首页隐藏模块导航，仅通过四张领域卡片进入；进入模块后顶栏展示当前模块的二级菜单。窄屏隐藏顶部二级导航，改为四个快捷入口与“更多”底栏；“更多”内含其他页面，并可以把任意功能替换为第四个快捷入口。
7. 已为当前有业务实现的工时页（打卡、记录、统计）、账本页（流水、账户、报表、定时任务、管理、成员与权限、回收站、操作日志）和设置页补充可点击的静态工作区草图。AI 交互在草稿中仅模拟本地反馈。正式实施需要复用现有账本 AI 预览/确认契约，并为任务、知识库和跨域 Agent 设计新的 API、权限与事件边界。
8. 所有卡片统一具备错峰入场与悬浮反馈；子页面的卡片、表格、日历、趋势、分类排行和设置行直接取自 `frontend/src/router/index.js`、`frontend/src/App.vue`、账本与工时 View 组件以及账本编辑/筛选组件的字段和结构，不以线上网站或通用占位文案作为功能依据。
9. 账本总览按 `LedgerView.vue` 补齐收入、支出、结余、资产、时间摘要、每日支出、预算、分类排行、年度柱状图、年度走势、月度记账日历、最近交易、账户、AI 预览确认、导入进度和首页卡片编排；流水页按实际组件补齐筛选字段、编辑字段、列信息与离线同步状态。
10. 管理页和成员权限页的内部 Tab 可直接切换，以便在静态稿阶段检查分类、商家、项目、账本、成员和角色权限各自的布局；任务和知识库尚未在当前产品实现，草稿中的页面只用于表达未来信息架构，不代表已有业务能力。
11. 配色风格切换已恢复：明亮黄、海盐青、森林绿、莓果粉。桌面端位于顶部“配色”，手机端位于“更多”，设置页也保留同一组色板。配色只切换设计 token，不改变信息架构。
12. 报表静态页与 `LedgerReportsView.vue` 的 11 个真实报表键一致：基础统计、分类、账户、商家、月报、支出分类、收入分类、账户详情、成员、项目分类和项目。源码中的“支出分类”和“收入分类”分别承载成本管理与收入管理看板，不再额外虚构两个重复 Tab。报表库保留添加、移除、排序，日期保留按年、按月、自定义，以及 PNG/PDF 导出入口。
13. 页面统一卡片 token：卡片间距 20px、内边距 24px、圆角 20px；标题到说明、说明到数据之间使用固定垂直节奏，避免不同模块出现卡片大小和 margin 不一致。
14. 管理功能以 `/ledger/manage?view=` 的真实组织方式表达：账户、分类、商家、项目、账本、成员与角色、回收站、操作日志共享管理页结构；桌面端保留表格，移动端按源码方向转为可横向查看或紧凑行布局。

## 从草稿到正式重构的前置条件

静态稿已由用户确认为正式重构基准。正式实现保留现有 Vue 3/Vite/Pinia 结构、账本的 local-first sync-engine、OpenAPI 生成客户端、路由级加载与既有响应式/无障碍验收门禁。任务、知识库与通用 Agent 仍属后续阶段，必须先完成领域模型、后端模块和 API 合约，不能仅由前端页面替代。

## 正式重构进度

正式前端调整已开始。原有生产前端在修改前备份至 `/Users/jianshengnan/Downloads/Projects/salary-sync-frontend-original-20260920`，备份包含当前 `src/`、配置和依赖清单，不包含 `node_modules`、构建产物与草稿临时目录。

正式视觉重构已落地：`/` 使用 GPT 式 AI 对话工作台，首页不显示业务模块导航。桌面端提供可收起的历史会话侧栏，主区域展示当前对话记录，底部固定输入框支持文字、文件、图片和浏览器语音录制；尚未选择历史会话时，四张领域入口卡居中显示。会话和附件记录按登录用户保存在本地，切换、删除和新建会话均不影响现有后端业务数据。进入账本、工时或设置后，由同一顶栏展示当前模块及二级导航，不再使用固定左侧栏。

移动端首页使用抽屉式历史会话栏并隐藏业务底栏，避免和底部对话输入框冲突；进入具体模块后恢复四个快捷入口与“更多”的浮动底栏，第四项可以在统计、流水和设置之间自定义并持久化。

账本总览已调整为草稿定义的三张淡彩收支卡、独立总资产卡、三张周期卡和后续双列内容区；同一行的左右卡片采用等高布局并对齐底边，顶部快捷操作统一为等尺寸纯图标按钮。流水、管理、定时任务、报表以及工时打卡/记录/统计继续保留真实业务字段和交互。全局采用一致的内容卡圆角、卡片间距、内边距、标题节奏和轻量入场/悬浮动画，移动端改为单列且不允许金额或控件横向溢出。

生产端提供日光、海洋、森林、莓果和暗夜五套完整配色，主题会同时改变页面背景、文本、边线、功能卡和强调色；暗夜主题同时启用深色页面语义和对应的图表、卡片对比度。桌面入口位于顶栏主题菜单，移动端位于“更多”，设置页保留相同选择。当前未实现的知识库和任务仍明确显示“即将开放”，没有虚构后端能力；首页的本地意图路由只跳转到已经实现的账本、报表、流水和工时页面。

暗夜主题的二级导航选中态使用低饱和灰蓝底、浅色文字和细描边，避免高亮强调色在深色顶栏中形成接近纯白的突兀胶囊，同时保持悬停态与选中态之间可辨识的层级。
