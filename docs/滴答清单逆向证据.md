# 滴答清单逆向证据与复刻基线

> 采集时间：2026-10-14。采集方式：用户已明确授权的本机持久 Chrome/CDP 与 Playwright 兼容流程。原始截图、渲染后 DOM、交互控件和请求记录保存在被 Git 忽略的 `.local/dida365-evidence/`，不进入版本库。

## 已采集页面

- `#q/today/tasks`：今天任务页，三栏工作台、清单/标签/过滤器分组、任务列表、日历摘要、AI 助手入口。
- `#q/today/tasks/<taskId>`：任务详情页，保持任务工作台并展开右侧详情编辑区域。
- `#c/all/calendar/m`：月历页，完整月份网格、农历/节气、清单筛选和任务卡片。
- `#focus`：番茄专注页，计时器、专注统计、历史记录。
- `#q/all/habit`：习惯页，按日期列展示习惯完成状态和连续统计。
- `#countdown`：倒数纪念日页，倒数卡片、已过期/已完成日期状态。
- `#ai`：滴答助手页，会话侧栏、建议操作和隐私授权提示。
- `#s`：搜索页，搜索条件、保存过滤器和结果分组。

## 观察到的稳定行为

1. 任务页左侧组织层按“所有/今天/明天/最近 7 天/收集箱 → 清单 → 过滤器 → 标签”分区；分区可折叠，列表对象支持排序和编辑。
2. 中间任务区按日期分组显示任务，顶部包含新增、排序、显示选项和更多菜单；点击任务不会离开工作台，而是打开右侧详情。
3. 月历页使用完整月网格，月首月末允许显示相邻月份日期；相邻月份日期使用弱化颜色。清单、过滤器和标签是日历来源筛选器。
4. 右侧详情包含标题、日期时间、重复、提醒、优先级、标签、清单、描述、检查项和活动记录；保存和删除均在详情上下文内完成。
5. 日历日期支持新增任务、专注、工时和流水；已有卡片进入对应对象编辑流程。
6. 专注、习惯、倒数日是独立一级效率页，但保留统一的左侧导航、顶部新建入口和 AI 助手入口。
7. 搜索页提供条件筛选与“保存为过滤器”，结果按清单、标签、日期、优先级、类型和状态分组。

## 复刻范围与边界

- 本轮证据覆盖当前账号可访问的主要一级页面和任务详情入口；删除、永久清除、批量完成等破坏性操作没有自动点击，只记录控件和代码可观察行为。
- 网络记录包含渲染期间浏览器捕获到的请求 URL、方法、状态和资源信息；不会导出 Cookie、Token 或请求中的账号密钥。
- 本项目已有任务域实现和后端数据契约，后续复刻按“壳层布局 → 任务工作台 → 日历/效率页 → 搜索与 AI”的增量落地，并用同一批页面截图做回归对比。
